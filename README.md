

# 🚗 Used Car Price Prediction

A machine learning regression project that predicts the **estimated price of a used car** based on its specifications, mileage, accident history, ownership, and colors.

---

## 📋 Overview

- **Type:** Regression
- **Goal:** Predict used car prices
- **Deployment:** Streamlit Web App

---

## 📊 Dataset

The dataset contains information about used cars.

### Features

- `name` — Car model
- `year` — Manufacturing year
- `miles` — Mileage
- `accidents` — Number of accidents
- `Owner` — Number of previous owners
- `exterior_color` — Exterior color
- `interior_color` — Interior color
- `price` — Target variable

---

## 🔍 Project Workflow

1. Data preparation
2. Feature preprocessing
3. Model training
4. Model evaluation
5. Model saving using `joblib`
6. Streamlit deployment

---

## 🤖 Model

The trained regression model is saved in:

```text
final_model.pkl
```

The preprocessing pipeline is saved in:

```text
preprocessor.pkl
```

Prediction workflow:

```text
User Input
    ↓
Preprocessing
    ↓
ML Model
    ↓
Estimated Price
```

---

## 📱 Streamlit App

The user can select:

- 🚗 Car Name
- 📅 Year
- 🛣️ Miles
- 💥 Accidents
- 👤 Owners
- 🎨 Exterior Color
- 🪑 Interior Color

Then the application displays the **estimated car price**.

## ▶️ Run Locally

Install the required libraries:

```bash
pip install streamlit pandas scikit-learn joblib
```

Run the application:

```bash
streamlit run app.py
```

The app will open at:

```text
http://localhost:8501
```
